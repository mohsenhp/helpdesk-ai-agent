# Runbook RB-0023: Printer Escalation

## Purpose
This runbook describes how to investigate and resolve recurring Printer problems.

## Steps
1. Search open tickets where category is "Printer".
2. Identify priority High or Critical tickets.
3. Check related incidents.
4. Review recent changes implemented in the last 14 days.
5. Contact the owning support team.
6. Update affected users.

## Rollback
If a recent change caused the issue, mark the change as Rolled Back and link it to the related incident.

## SQL tables
tickets, incidents, changes, assets, users
